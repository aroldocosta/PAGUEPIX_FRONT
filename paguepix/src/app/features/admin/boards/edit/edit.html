Hardware Control

A Placa de Hardware (Board) é a interface de comunicação de baixo nível que executará os Scripts e que ficará armazenada dentro do Dispositivo (Device - QRCode).

Certifique-se de que o Hardware(Board) (clientId) esteja perfeitamente preenchido, pois é a identificação unificada que o Broker usará para autorizar a conexão do módulo.
